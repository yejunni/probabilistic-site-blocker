# 확률 기반 사이트 차단

유튜브에 들어가려고 하면 **확률로** 통과 여부를 정하는 크롬 확장 프로그램입니다.
오래 기다릴수록 확률이 올라가고, 실패하면 처음부터 다시 기다려야 합니다.
통과하면 하루 한도 안에서 원하는 만큼만 볼 수 있습니다.

> 고등학교 정보과학 수업 프로젝트

---

## 어떻게 동작하나

```
유튜브 접속 → 차단 화면 (통과 확률 표시)
   ↓ [시도하기]
확률로 주사위를 굴림
   ├─ 통과 → 몇 분 볼지 정함 → 유튜브 열림 → 시간이 끝나면 다시 차단
   └─ 실패 → 기다린 시간이 0으로 초기화 → 0%부터 다시
```

- **기다린 시간이 길수록 확률이 오릅니다.** 상한이 있어서 아무리 기다려도 100%는 안 됩니다.
- **실패하면 처음부터입니다.** 80분 기다려서 72%였는데 실패하면 다시 80분을 기다려야 합니다.
- **하루 한도가 있습니다.** 통과해도 그날 남은 시간 안에서만 볼 수 있습니다.
- 이용 중에는 화면 우측 상단에 **남은 시간**이 뜹니다.

## 주요 기능

- **확률 곡선을 직접 만들기** — 설정 화면의 그래프에서 점을 위아래로 끌어 모양을 정합니다.
  S자 / 직선 / 로그 곡선도 고를 수 있습니다.
- **설정 화면** — 하루 한도, 확률 상한, 프리셋(느슨/보통/엄격), 곡선 미리보기
- **기록 통계** — 시도 횟수, 통과율, 사용 시간, 최근 7일 (Supabase 연결 시)
- **여러 기기 묶기** — 같은 *공유 코드*를 넣으면 크롬 프로필이나 구글 계정이 달라도
  하루 한도와 기다린 시간을 함께 씁니다 (Supabase 연결 시)

## 설치

빌드 과정이 없습니다. 파일을 그대로 크롬에 올립니다.

1. 이 저장소를 내려받습니다 (`git clone` 또는 ZIP)
2. 크롬 주소창에 `chrome://extensions` 입력
3. 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더 선택
5. `youtube.com`에 접속하면 차단 화면이 뜹니다

> 코드를 고친 뒤에는 확장 카드의 **새로고침(↻)** 을 꼭 눌러야 반영됩니다.

**설정 화면 여는 법**: 차단 화면의 **[설정]** 버튼, 또는 주소창 오른쪽 퍼즐 조각(🧩) → 확장 이름 클릭

### 기록·공유 기능 켜기 (선택)

Supabase 없이도 차단·판정·설정은 전부 동작합니다.
기록 통계와 여러 기기 공유를 쓰려면 아래를 설정하세요.

1. [Supabase](https://supabase.com)에서 프로젝트를 만듭니다
2. **SQL Editor**에서 `supabase/` 폴더의 파일을 **이 순서로** 실행합니다
   1. `schema.sql` — 기록 테이블
   2. `stats.sql` — 통계 함수
   3. `shared_state.sql` — 한도 공유 테이블과 함수
3. `secrets.example.js`를 복사해 **`secrets.js`** 로 저장하고 두 값을 채웁니다
   - `url`: Project Settings → API → Project URL
   - `anonKey`: 같은 화면의 **`anon` `public`** 키
4. 확장을 새로고침합니다
5. (여러 기기 묶기) 설정 화면의 **공유 코드**에 영문·숫자 4자 이상을 넣고 저장합니다.
   묶고 싶은 모든 프로필에 같은 코드를 넣으세요

> ⚠️ **`service_role` 키는 절대 넣지 마세요.** 확장 프로그램은 사용자 PC에서 도는 코드라
> 누구나 파일을 열어볼 수 있습니다. `anon` 키만 쓰고, `secrets.js`는 GitHub에 올라가지 않습니다.

## 폴더 구조

| 파일 | 역할 |
|---|---|
| `manifest.json` | 확장 프로그램 설정 |
| `rules.json` | 유튜브를 차단 화면으로 보내는 규칙 |
| `config.js` | 확률·시간 관련 기본값 모음 |
| `probability.js` | 경과 시간 → 통과 확률 계산 (계산만 함) |
| `background.js` | 판정, 차단 해제/재차단, 알람, 설정·상태 저장 |
| `blocked.html` / `blocked.js` | 차단 화면 |
| `options.html` / `options.js` | 설정 화면 |
| `timer.js` | 유튜브 위에 남은 시간 표시 |
| `supabase.js` | Supabase 통신 (기록·통계·공유) |
| `supabase/*.sql` | 테이블과 함수 만드는 SQL |
| `secrets.example.js` | Supabase 키를 넣는 틀 (`secrets.js`로 복사해서 사용) |

## 기술 메모

- **Manifest V3** 확장 프로그램. 순수 HTML/CSS/JS, 외부 라이브러리 없음
- 차단은 `declarativeNetRequest`로 합니다. 통과하면 **우선순위가 더 높은 허용 규칙**을
  덮어씌워 풀고, 시간이 끝나면 그 규칙만 걷어냅니다
- 이용 시간 종료는 `setTimeout`이 아니라 **`chrome.alarms`** 를 씁니다.
  서비스 워커는 몇 초 만에 잠들어서 타이머가 사라지기 때문입니다
- 확률 곡선의 **점 잇기**는 단조 삼차 에르미트 보간(Fritsch–Carlson)을 씁니다.
  흔한 Catmull-Rom은 점 사이에서 출렁여 확률이 내려가는 구간이 생기기 때문입니다
- Supabase는 **표를 직접 읽지 않고 함수로만** 접근합니다. 로그인이 없어서
  "자기 것만 읽기" 규칙을 세울 수 없으니, 표는 막아두고 요약만 돌려주는 창구를 열었습니다
- Supabase에 접속하지 못해도 확장은 멈추지 않습니다 (로컬 값으로 계속 동작)

## 한계

**완전한 차단이 아니라, 우회에 마찰을 주는 도구입니다.**
확장 프로그램은 설치된 크롬 프로필 안에서만 동작하므로 코드로 막을 수 없는 우회가 있습니다.

- 시크릿·게스트 모드, 다른 브라우저, 확장 끄기
- 확장이 설치되지 않은 다른 프로필·계정
- Supabase 연결이 끊긴 상태에서 한도를 되돌리는 것 (차단 화면에 *마지막 동기화* 시각이 표시됩니다)

공유 코드는 **비밀번호가 아닙니다.** 같은 코드를 아는 사람은 같은 묶음이 되고 그 묶음의
통계를 볼 수 있으니, 남이 추측하기 어려운 값으로 정하세요.
